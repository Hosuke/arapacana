# 字门次第 · Arapacana

**华严四十二字门 × 诸尊种子字的字相与法义导读网站。**

在线访问：<https://arapacana.oneness.ren/>（旧址 hosuke.github.io/arapacana/ 由 GitHub Pages 自动转至新址）

> 中文名为**字门次第**。Arapacana（a · ra · pa · ca · na）是四十二字门之前五字，亦见于文殊五字真言。
> 「字门」摄华严四十二字与诸尊种子字，「次第」摄由闻声、识字、观义而归于日用的学习层次。

本项目与 [hosuke/mandala](https://github.com/hosuke/mandala)（金胎不二 · 两部曼荼罗）相互独立，仅作法义与图式互参；不共享代码、数据或开发分支。

## 立意

> 循字入义，依法观文；图为方便，不代法义。

- **依法观文**：依所列经论与公开仪轨整理，不自立教判，也不授灌顶、口传或认证。经义有疑，宜核对原典，并请教具德善知识。
- **以图助学**：月轮、字轮与次第图帮助辨认字相、方位与法义；不以图式代替本尊、坛城、仪轨与真实修持。
- **返观自省**：清单只供记录闻思与日用，不判定证量，也不以感应或梦境分高下。

## 使用边界

本站只作字相辨识、法义导读与观学辅助，不称传法，不替代皈依、戒法、灌顶、口授及具德善知识。月轮、种子字、五相成身、上转下转等各有传承语境：有师承者依师教；未受相关教授者，以闻思与字相学习为限。

礼敬尊像、亲近善知识自有其法义。本站避免以个人崇拜代替依法修学，并不否定礼敬与依止。

## 法源与分层

本站区分三层，不把后世解释冒充经文：

1. **经文门名**：取《八十华严·入法界品》善知众艺童子所说四十二字门。
2. **不空本释义**：悉昙、IAST及“悟一切法……”逐字释义取不空《四十二字观门》；《大智度论》与澄观疏钞作会通复核。
3. **字轮图示**：参不空《华严经入法界品字轮瑜伽仪轨》；图示不等同完整仪轨。

## 字形数据口径

依不空《四十二字观门》的悉昙字与罗马转写，本站现列**单字三十一、二辅音合字十一**；“合字”按悉昙Unicode串是否含合字符判断。汉字采用《八十华严》的译音字，只作注音参照，其字数不能当作梵字合字数。未经原典直接证实的扩算已撤下。逐字出处、异本裁决及可重复生成命令见 [`research/cbeta/README.md`](research/cbeta/README.md)。

## 技术

React + TypeScript + Vite + Tailwind CSS。悉昙字形由 Noto Sans Siddham 网络字体承载；月轮、字轮使用 SVG/Canvas 绘制；磬音由 Web Audio 合成。favicon 为金刚界大日如来种子字「鑁」vaṃ的月轮字相。

```bash
npm ci
npm run lint
npm run build
```

生产构建输出至 `docs/`，GitHub Pages 从 `main:/docs` 发布。
