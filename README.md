# Arapacana · 阿囉波遮那

**华严字母 × 诸尊种子字 —— 去人格化的种子字观行课程网站。**

在线访问：<https://hosuke.github.io/arapacana/>

> 定名：梵名 **Arapacana**，中文名即其音译「**阿囉波遮那**」（a-ra-pa-ca-na）——
> 四十二字门之前五字，亦即文殊五字真言。
> 名从经出：站名本身即全站主旨「两门一音」的示现——
> 同一五音，是华严字母的开端，也是文殊的真言。
> 「字门次第」退为六阶课程模块之名，恰如其分。

独立项目。与 [hosuke/mandala](https://github.com/hosuke/mandala)（金胎不二·两部曼荼罗引擎）仅为法义互参关系：零代码依赖、零数据共享、零分支关系。对 mandala 引擎的任何修改与增添，另行 fork 或 PR 处理，不混入本项目。

## 立意

> 让众生在法上安住即可，次第了义。

- **依法不依人**：无上师、无认证权威、无不可问的教义。四依四不依为课程宪章。
- **结构即教义**：尊名作函数名解——观音＝大悲之函数，文殊＝般若之函数，大日＝法界体性之函数。膜拜在本系统中没有对应的数据类型。
- **能验可复**：每阶成就标准是可自勘的经验指标，勘验权完全在行者自己手里。

## 内容架构

| 区块 | 内容 |
|------|------|
| 序曲 | 入站滚动叙事「一音两门」六幕：序（先有此音）→ 同源（般若字门是种子字的显教前身）→ 同构（一放四十二、四十二归一）→ 合流（不空字轮瑜伽：右旋布列、摄入心月轮）→ 相异（横向遍门 ⇄ 纵向总持，两端同归）→ 配位（四十二字配四十二位，唱一字如历一位）→ 收束（诸法本不生，开门进站） |
| 卷首 | 程序生成月轮阿字（Canvas + Noto Sans Siddham，零图片） |
| 宪法 | 立课三条：依法不依人 · 结构即教义 · 能验可复 |
| 入门 | 三条入路按行者身份分流：华严字母门（遍入）· 东密种子字门（总持）· 单字专修（一门深入） |
| 字轮 | 华严四十二字母交互字轮——依不空《字轮瑜伽仪轨》「于月轮内右旋布列四十二梵字，悉皆金色」；悉昙为准、汉字注音；逐字示般若门名与遮诠义（《八十华严》卷七十六、澄观疏钞）；结构三数：33·8·1、42×12=504、一即一切 |
| 字帖 | **每一字的独立界面**：表法（月轮悉昙真形与结构）· 表意（「唱某字时，入般若波罗蜜门，名……」及遮诠）· 观法（入座→持字→观义→字亡四步）；可「以此字入观」携字直入日课 |
| 两门 | 华严字母 ⇄ 诸尊种子字：文殊五字即四十二字门之前五字（两门的钥匙）；种子字与字轮的交离对照（每枚种子字亦有独立字帖）；五大种子字配五轮（点轮开对应字门字帖） |
| 六阶 | 声门 → 字门 → 义门 → 轮门 → 不二门 → 无字门；每阶「讲义·观法·行持·勘验·了义点」 |
| 日课 | 十五分钟一座：入座（身）→ 持字（语）→ 观义（意）→ 回向（行）；磬音 Web Audio 程序合成（零音频资源）；持字可选：阿字一门／文殊五字／**四十二字门任一字／诸尊种子字任一字**（单字专修，月轮即现该字悉昙，观义引导随字而换） |
| 勘验 | 六阶自勘清单，localStorage 仅存本地；勾满不判「通过」，只给「再行一周，或可进一阶」——判定在法，不在程序，更不在人 |
| 法源 | 次第所依经论与仪轨勘定说明 |

## 法源

《大日经》阿字本不生 · 《金刚顶经》五相成身观 · 《华严经·入法界品》四十二字门（八十华严卷七十六）· 《大智度论》字门释义 · 不空《顿证毗卢遮那法身字轮瑜伽仪轨》 · 澄观《华严经疏钞》。

观行次第由出家师承依弘法大师空海所传仪轨文献勘定：去除的是尊像膜拜与人身依止，不去的是观行本身的结构。

## 技术

React + TypeScript + Vite + Tailwind CSS。悉昙字形由 Noto Sans Siddham 网络字体承载，月轮、字轮皆程序生成（SVG/Canvas），磬音程序合成——**整站零图片、零音频资源**（字体为唯一外部依赖，断网退化为系统 serif，法义不失）。

```bash
npm ci
npm run dev
npm run build
```

生产构建输出至 `docs/`，GitHub Pages 从 `main:/docs` 发布。

## 数据声明

勘验勾选、修持座数仅存于行者浏览器的 localStorage：不上传、不认证、法缘只属于行者自己。清除浏览器数据即失。
